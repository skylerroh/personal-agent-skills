# Volleyball rotations

## Establish the constraints

- Read each player's name, stated gender when relevant to eligibility, ordered position preferences, availability, and any stated setter experience. Preserve preference order. Treat a preference for setting and demonstrated setting strength as separate inputs. Never infer gender from a name or strength from preference order.
- Resolve the decisions that change the lineup together. Confirm the number of teams and players per side, the co-rec rule (including minimum on-court count, row or order requirements if any), whether each available player must enter each set or each game, and whether play uses a specific official ruleset or house rules. Clarify whether a game means a set or a match when it affects participation. Ask for the number of sets or matches if planning sit-outs across them.
- Use the organizer's rules for co-rec eligibility, including who counts toward any required minimum. Check the named event's rules or ask for them when needed. Mixed play alone does not establish a minimum. For an official plan verify the current applicable rulebook and event exceptions, including serve and receive positioning, substitutions and re-entry, and libero rules if used. The [FIVB rules index](https://www.fivb.com/volleyball/the-game/official-volleyball-rules/) is a starting point for events using FIVB rules.
- If answers are pending, produce a clearly marked provisional draft when feasible. State assumptions about team size, co-rec, participation, and rotation. In a casual draft with a full side, use six-player clockwise rotation as a starting point. Use a reduced side or fixed rows only as an explicitly labeled house-rule option when appropriate.

## Build the lineup

1. Satisfy eligibility, availability, lineup and substitution rules, and required participation first. Favor the strongest known available setter staying on court. Start with a 5-1 when a six-player side has a suitable setter who can cover all six rotations. If setter strength is unknown, mark the choice as provisional. Use a 6-2 only when two suitable setters can cover opposite halves of the cycle and the switch serves a concrete goal. For reduced sides, use a designated setter or a simple shared setting assignment and describe how it works.
2. Fill remaining roles using ranked preferences and coverage needs. Choose a recognizable starting lineup with a backup setter or handoff plan when needed. For multiple teams, partition the roster so each side can meet its own eligibility and setting needs. When play in every set is optional, distribute bench time across sets while retaining setting coverage. Explain meaningful preference tradeoffs.
3. Use numbered court spots as viewed from the team's end line facing the net. Front row left to right is 4, 3, 2. Back row left to right is 5, 6, 1. For standard rotation, advance each lineup slot on each side-out through 1 → 6 → 5 → 4 → 3 → 2 → 1. R1 is the opening lineup. Show court assignments at the applicable serve or receive alignment, and distinguish any post-serve switches. A setter moving to the net retains their rotational front- or back-row status.
4. For house rules, define what advances each step, how serving order works, and who stays in each row. Show six numbered steps with explicit vacant zones when short-handed. If the house pattern repeats within six steps, show the repeats. If it runs longer, show all remaining steps on continuation sheets and explain when to restart. Do not assume a fixed row and the service queue have to move together.
5. For every change, name the outgoing player, incoming player, slot, and trigger. Avoid using arrival at a late rotation as the only trigger for mandatory participation because a set may end before that rotation. Use an early, legal trigger and a fallback if the set runs short. Distinguish a planned entry from a guarantee when timing or rules can prevent it. If hard constraints conflict, explain the conflict and identify the specific constraint or roster change that would make a plan feasible. Label any conditional option.

## Verify and deliver

- Walk each team's entire cycle and each scheduled substitution state, including the wraparound and any fallback. Check unique players on court, slot movement and next server, active setter and row status, bench availability, and co-rec eligibility throughout. Check both lineups before and after each entry. Verify per-set or per-game participation from actual entry plans, not bench assignments.
- Deliver a printable PDF with six labeled court diagrams per distinct team lineup and rotation pattern. Label the team and covered sets, numbered spots, active setter and row, server, bench and substitution triggers, and any switches. Include playing roles in a lineup key when they differ from the numbered spots. If a substitution changes the setter or a switch, put the updated cue on the sheet. Use a short legend and keep gender off the printout unless needed to apply the rule. Mark provisional plans and house rules on the sheet. Reuse a sheet for identical sets and label which sets it covers.
- For the default print layout, see [the PDF renderer](scripts/render_rotations.py) and run `python scripts/render_rotations.py --help` from the skill directory for its JSON input format. It requires ReportLab. Use another PDF generator if needed for custom diagrams or unavailable dependencies. Render every final page and check legibility, clipping, and correspondence to the verified lineup before handing it over.
- Keep revisions easy. When the roster or rules change, update the affected lineups, rerun the checks, and replace the printout. Summarize the consequential changes alongside the revised PDF.
